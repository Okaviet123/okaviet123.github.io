## 1. 目的とKPI

### 1.1 最終目標(North Star)

**紹介リンク経由のTria登録数(→カード有効化数)の最大化。**

Triaの紹介報酬は「被紹介者が獲得するTria Pointsの10%」+登録特典($5相当、時期により変動)という構造のため、
「登録させて終わり」ではなく「登録→KYC→入金→カード利用」まで到達する読者を集めるほど報酬が増える。
したがって本サイトは *登録意欲の高い検索ユーザー* を集め、*行動まで導く導線* を最優先に設計する。

### 1.2 KPIツリー

```
紹介報酬
└─ 紹介リンククリック数 (GA4: affiliate_click)
   ├─ セッション数 (GA4) ← 検索流入 (Search Console: 表示回数×CTR)
   └─ CTAクリック率 = affiliate_click ÷ セッション
```

| 段階 | 指標 | 見る場所 | 初期目標 |
|---|---|---|---|
| 集客 | 検索表示回数・掲載順位 | Search Console | 対象クエリで10位以内 |
| 集客 | 検索CTR | Search Console | 4%以上(順位相応) |
| 回遊 | エンゲージメント率・平均エンゲージメント時間 | GA4 | 60%以上 / 1分以上 |
| 転換 | affiliate_clickイベント数 / セッション | GA4 | 8%以上 |
| 転換 | クリック位置別の内訳(link_location) | GA4 | 弱い位置を毎週改善 |

実際の登録数はTriaアプリ側のダッシュボードでしか見えないため、
**サイト側の代理指標は affiliate_click** とする(§7)。

## 2. ターゲット

### 2.1 ペルソナ

1. **クリプト既保有層(主ターゲット)**:仮想通貨を保有していて「使い道」を探している。還元率・手数料・セルフカストディに反応する。検索例:「クリプトカード おすすめ」「仮想通貨 カード 決済」
2. **Tria指名検索層(最も転換率が高い)**:X(Twitter)やYouTubeでTriaを知り、登録方法・招待コード・評判を調べている。検索例:「Tria 招待コード」「Triaカード 評判」「Tria 使い方」
3. **ポイ活・キャンペーン層**:登録特典($5)やエアドロップ期待で動く。検索例:「Tria 5ドル」「Tria エアドロ」

**優先順位は 2 > 1 > 3。** 指名検索は競合が少なく転換率が最も高い。まず指名系ロングテールを全て取りに行く。

### 2.2 前提知識(コンテンツが答えるべき不安)

- 「怪しくない?」→ 安全性・セルフカストディの仕組み・リスクを正直に書く
- 「日本で使える?」→ 日本居住者の登録可否・KYC書類・カード発送を明記
- 「手数料は?」→ 年会費・還元率・チャージ手段を表で明示
- 「招待コードはどこ?」→ 即答+リンクで自動適用できることを伝える

- 導入手順:GA4でプロパティ作成 → ウェブストリームでURL `https://okaviet123.github.io` を登録 → 測定IDを `site.js` に貼る → push
- カスタムイベント:
  - `affiliate_click`:紹介リンククリック。パラメータ `link_location`(hero/sticky等)、`page_path`

- GA4管理画面で `affiliate_click` を**キーイベント(コンバージョン)に設定**する

### 7.2 Search Console(サチコ)

- プロパティ:URLプレフィックス `https://okaviet123.github.io/`(ルート所有権はHTMLタグ or DNSで検証。GA4連携でも可)

- 登録後、各URLを「URL検査→インデックス登録をリクエスト」

## 8. 改善運用ループ(AIが回す週次ルーチン)

**毎週1回、以下をAIに依頼する。人間の作業はGA4/サチコの画面のスクショ(またはエクスポートCSV)を渡すことのみ。**

```
【週次改善プロンプト(コピペ用)】
tria/SPEC.md の §8 に従って週次改善をして。
添付:GA4(過去7日 vs 前週:セッション、affiliate_click、link_location別内訳、
ページ別エンゲージメント)、サチコ(クエリ別 表示回数/クリック/CTR/順位)、
気づいたこと:(あれば)
```

AIの実行手順:

1. **転換の点検**:`affiliate_click ÷ セッション` が8%未満のページ → CTAの位置・文言・数を変更
2. **CTRの点検**:サチコで「表示回数が多いのにCTR低い」クエリ → 該当ページのtitle/descriptionを書き換え
3. **順位の点検**:11〜30位のクエリ → 該当ページに見出し・本文を追記して強化(新規ページより既存強化を優先)
4. **需要の発見**:サチコの未対応クエリ+Googleトレンド急上昇語 → faq.htmlに質問追加、または新ページ作成(§3.3)
5. **鮮度の維持**:還元率・手数料・特典額をアプリ/公式で確認し、変わっていたら全ページ更新+「最終確認日」更新
6. 変更は全てこのブランチ運用ルールに従いコミット&プッシュ。変更点と「来週見るべき指標」を報告して終了

**禁止事項**:誇大表現の追加(§9)、還元率等の未確認数値の記載、既存ルートサイトの変更。

## 9. コンプライアンス(必読・変更禁止)

1. **PR開示(ステマ規制対応)**:全ページの冒頭に「本サイトには紹介リンク(PR)が含まれます」を明示。CTAリンクは `rel="sponsored"`
2. **投資助言をしない**:利益を保証する表現、投資判断を促す表現は書かない。「投資助言ではない」旨を免責に明記
3. **リスクの明示**:暗号資産の価格変動リスク、Triaが日本の暗号資産交換業者登録の枠外である(海外サービスである)こと、自己責任である旨を明記
4. **誇大表現の禁止**:「必ず儲かる」「絶対」「無料で$5もらえる(条件を伏せる)」等は禁止。特典は「変更される場合がある」を常に併記
5. **数値の鮮度管理**:還元率・年会費・特典額には「最終確認日」を明記。確認できない数値は書かない
6. **非公式であることの明示**:Tria公式とは無関係の個人サイトであることをフッターと免責に明記

## 10. 事実データ(2026-08-22時点の調査。掲載時は都度再確認)

- Tria:セルフカストディ型のクリプト・ネオバンクアプリ(取引・運用・決済)。資産はTSSウォレットでユーザー管理、決済時のみ変換
- カード:Visaネットワーク。3ティア制(2026-08時点の一般的な紹介値:バーチャル 年$25・還元1.5%/シグネチャー 年$109・還元4.5%/プレミアム 年$250・還元6%。還元対象となる月間利用額に上限あり:$100/$1,000/$2,000)※時期・キャンペーンで変動、「最大8%」と案内される時期もある
- 日本:居住者の登録・カード発送に対応(2026年時点)。KYCはパスポート/運転免許証/マイナンバーカード+セルフィー
- バーチャルカードは即時発行、物理カードは発送に8〜12週間の事例あり
- Apple Pay / Google Pay 対応
- 登録には招待コード(アクセスコード)が必要。リンク経由なら自動適用
- 紹介プログラム:紹介者は被紹介者のTria Pointsの10%を獲得。被紹介者は登録特典($5相当と案内。変動あり)
- 利用不可:米国・ロシア・インド等、OFAC制裁地域
