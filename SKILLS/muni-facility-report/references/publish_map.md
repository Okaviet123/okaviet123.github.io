# 地図統合・コード化公開の設計（フェーズ7）

蒲郡市#2の着手時に追加。目的は「日本地図で自分の市町村を見つけて
クリックするとレポートに飛べる」という、読者が自分ごととして入り口に
たどり着ける着地を作ること。市が1つの間は不要だが、2つ目以降は
このフェーズを必ず通す。

## 設計方針

1. **著者側の作業ディレクトリ名は変えない。** `<CITY>/`（例: `TOYOHASHI/`,
   `GAMAGORI/`）はこれまで通りローマ字の市名。理由: フェーズ1〜6の
   スクリプト・CLAUDE.mdの規約が既にこの前提で書かれており、
   人間（Claude/レビュー担当）が読み書きする対象なので可読性を優先する。
2. **公開URL（読者がクリックする先）は総務省の全国地方公共団体コード
   （5桁、例: 蒲郡市=23214、豊橋市=23201）で固定する。** 市名の
   表記揺れ（ローマ字化の仕方、ひらがな/漢字）に依存しない恒久リンクに
   するため。コードは総務省「全国地方公共団体コード」または
   都道府県サイトの市区町村コード一覧で確認する（**推測しない。
   複数の独立した出典で一致を確認してから使う**——検索エンジンの
   自動要約だけで確定させると誤ったコードを使うリスクがある。実際に
   蒲郡市#2では最初のWebSearch要約が誤ったコード(23215=犬山市)を
   返し、2回目の検索で一次資料に近いページを突き合わせて訂正した）。
3. **公開先ディレクトリと著者ディレクトリを分離する。**
   `<CITY>/SITE/` が「原稿」、`report/<市町村コード>/` が「公開物の
   コピー」。`map/build_map.py` が `<CITY>/SITE/` を
   `report/<市町村コード>/` にコピーする。GitHub Pagesはシンボリック
   リンクを確実に配信しないため、コピーで持つ。

## `MUNICIPALITIES.csv`（リポジトリ直下）

| 列名 | 内容 |
|---|---|
| 都道府県コード | 2桁 |
| 都道府県名 | 例: 愛知県 |
| 市町村コード | 5桁（全国地方公共団体コード、チェックディジット無し） |
| 市町村名 | 例: 蒲郡市 |
| ディレクトリ | 著者ディレクトリ名。例: GAMAGORI |
| 状態 | `公開` / `作業中` / `未着手` のいずれか |
| 備考 | 任意。ブランチ名や着手状況など |

新しい市に着手した時点（フェーズ1完了時）でこのCSVに1行追加してよい
（`状態=作業中`）。`SITE/`が実際に生成されてから`状態=公開`に変える。

## `map/build_map.py` の挙動

1. `MUNICIPALITIES.csv` を読む。
2. 各行について、`<ディレクトリ>/SITE/index.html` が存在すれば
   `report/<市町村コード>/` へディレクトリごとコピーする（無ければ
   スキップし、地図上は「準備中」として扱う）。
3. `map/assets/japan-prefectures.svg`（都道府県単位の実形状SVG。
   出典・ライセンスは下記）を読み込み、CSVにある都道府県コードの
   グループを「レポートあり」として`map/index.html`に埋め込むJSONに
   変換する。
4. `map/index.html` を再生成する。既存の手書き編集は上書きされるので、
   このページを直接編集しない（CSVとSVGアセットを変更してから
   再生成すること）。

## `map/index.html` のUX仕様

- 全国SVG地図（47都道府県、実形状）を表示。レポートがある都道府県は
  着色・クリック可能、無い都道府県も薄い色でクリック可能にし
  「まだレポートがありません」と表示する（地図全体が本物であることを
  示し、将来の拡張を予感させる。無効化して灰色に沈めるより誠実）。
- クリックした都道府県にSVGの`viewBox`を寄せてズームするアニメーションを
  入れる（`getBBox()`でその都道府県グループの範囲を取り、パディングを
  足してズーム）。「全国に戻る」ボタンで解除する。
- ズームと同時に、サイドパネルにその都道府県の市町村一覧を表示する。
  `状態=公開`の市町村はリンク（`report/<コード>/`へ）、それ以外は
  「準備中」のラベルのみ（存在しないURLへは絶対にリンクしない）。
- 都道府県名・市町村名の文言はSVG内の`<title>`要素（都道府県名）と
  `MUNICIPALITIES.csv`（市町村名）からそのまま使う。ハードコードした
  日本語名の一覧を別途Python側に持たない（表記のズレ・誤記のリスクを
  減らすため、真実の情報源を1箇所にする）。

## 地図データの出典・ライセンス

`map/assets/japan-prefectures.svg` は Geolonia が公開している
都道府県単位のSVG地図（<https://github.com/geolonia/japanese-prefectures>）
をそのまま使用。同リポジトリのREADMEに「Wikipediaの日本地図.svgを
ベースにしており、ライセンスはGFDLとする」と明記されている。そのため
このスキルを使う各サイトのフッターに、地図の出典表示
（例:「地図: Wikipedia『日本地図.svg』(GFDL) を元にGeoloniaが作成した
SVGを使用」+ 両リポジトリへのリンク）を必ず入れること。省略しない。

## 市町村単位の形状データについて（現状のスコープ外）

市町村境界の実形状（全国1,700超）は現時点では組み込まない。理由:
1. データ量・保守コストが大きい割に、都道府県内の市町村数は
   このシリーズの規模（当面は数市〜十数市程度）では一覧リストで
   十分読みやすい。
2. 都道府県レベルの実形状ズームで「自分の県を見つけてクリックする」
   という自分ごと感は十分満たせる。
3. シリーズが同一都道府県内で数十市に達するなど、一覧では読みにくく
   なった段階で、その都道府県だけ市町村単位のSVGを追加する
   （全国一括ではなく必要な県から段階的に）方針で拡張してよい。
