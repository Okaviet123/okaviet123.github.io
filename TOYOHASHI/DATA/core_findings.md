# 中核ファインディング（S3時点の素材メモ）

出典はすべて「豊橋市公共施設等総合管理計画2026-2055」（令和8年3月、
RAW/keikaku2026/sougou_kanri_keikaku_2026-2055_full.pdf）。
ページ番号は計画書に印字されたノンブル。引用時は必ず原文を再確認すること。

## 市自身の30年収支試算（建物系施設）— 中核図表1枚の最有力候補

計画書 p.52-53（第3章）:
- 今後30年間の維持・更新費用（長寿命化対策実施後）: **約4,392億円**
  - 内訳: 更新等 1,551億円 / 改修 2,000億円 / 維持管理・修繕 841億円
- 維持・更新にかけられる費用（2024年度実績 約108.9億円/年 × 30年）: **約3,268億円**
- 不足額: **約1,124億円（約26%不足）**
- 試算対象: 建物系施設（インフラ系、上下水道局、市民病院を除く）
- 市の結論: 施設保有量（延べ床面積）を **30年間で20%程度削減** する目標
  - 人口減少割合(約23%)まで削減すると124億円の余剰
  - 21%削減で維持・更新費用3,249億円 ≒ 充当可能額3,268億円（ほぼ均衡）

## 過去との比較（インフラ等を含む公共施設等全体・建物系と混同しないこと）

計画書 p.32付近（第2章）:
- 過去15年間の維持・更新費用実績: 総額約1,608億円、**年平均約107億円**
- 今後30年間の推計（長寿命化実施時）: 総額約6,905億円、**年平均約230億円 = 過去の約2.1倍**
- 長寿命化なしの場合: 年平均約504億円 / 長寿命化ありで年平均約378億円
  （※この504/378はp.32付近の別試算。230億円との対象範囲の違いを原文で要確認）

## 財政の現在地（第2章）

- 市税収入: 2019（令和元）年度に過去最高の663億円
- 2024（令和6）年度歳出決算: 1,512億円
- 旧方針(H29.3)時代の目標: 維持・更新費用の年約45億円確保（p.7付近）

## 図表1枚の構想（S4で確定）

「4,392億円 vs 3,268億円 → 1,124億円のギャップと、20%削減という市の答え」を
1枚で見せる。決算カード23年分の時系列（財政の体力の推移）と、
白書個別票の施設実名リスト（ギャップの中身が誰の使う施設か）を裏付け表にする。

## 未確認・要注意

- p.32の「230億円/年」とp.52の「4,392億円/30年≒146億円/年」は対象範囲が違う
  （前者はインフラ含む全体、後者は建物系のみ）。レポートで並べるときは
  対象範囲を必ず明記。混ぜると誤読を生む。
- 数字の引用はすべて原文ページの再確認を経てから公開版に載せる。
