# kessancard_timeseries.csv 抽出ノート

- 作成日: 2026-07-27
- スクリプト: `parse_kessancard.py`（TOYOHASHI直下）
- 入力: `RAW/kessancard/kessancard_H14.pdf` 〜 `kessancard_R06.pdf`（豊橋市 決算カード、総務省統一様式、23年分）
- 出力: `DATA/kessancard_timeseries.csv`（1行=1年度、UTF-8 BOM付き）
- 方式: `pdftotext -layout`（poppler-utils）の出力を正規表現で解析。Python3標準ライブラリのみ。

## 抽出結果サマリ

- **全23年度（H14〜R06）すべて抽出成功。**
- 空欄は以下のみ（いずれも「その年度のカードに項目が存在しない」ことによる正当な欠損）:
  - 実質公債費比率: H14〜H16（制度導入がH17決算のため様式に無い）
  - 将来負担比率: H14〜H18（健全化法によるH19決算からの公表のため様式に無い）
  - ラスパイレス指数: **全年度**（豊橋市の決算カード様式には記載が無いことを23年分の
    テキストで確認済み。列は残してあるがすべて空欄）

## 実行環境の注意（重要）

- H14, H16, H22〜H27 などのPDFはCJKフォントが非埋め込みで、poppler の
  `poppler-data` パッケージが無いと `pdftotext` が**空テキスト**を返す
  （stderr に `Missing language pack for 'Adobe-Japan1' mapping`）。
  本環境では `apt-get install poppler-data` を実行して解決した。
  スクリプトはこの状態を検知するとエラーメッセージを出して該当年度を欠損扱いにする。
- H14/H16 のファイルサイズが他の1/4程度なのはPDF生成ソフトの違いによるもので、
  **カードの様式・レイアウト自体は他年度とほぼ同一**だった。

## 年度による様式差異と対応

1. **住民基本台帳人口の基準日が年度で異なる。**
   - H14〜H24カード: 年度末 **3.31** 時点（例: H14カードは「(15)3.31」= 平成15年3月31日）
   - H25カード以降: 翌年 **1.1** 時点（住基法改正に伴う様式変更。H25カードは「(26)1.1」）
   - CSVでは `住基人口_基準日` 列に各カード記載の基準日をそのまま記録した。
     「1.1時点」の人口が取れるのはH25以降のみで、H14〜H24は3.31時点の値である
     （推測での換算はしていない）。
   - 関連: H23→H24で人口が 365,352 → 379,678 と約1.4万人増えるのは、
     2012年7月の住基法改正で**外国人住民が住民基本台帳に編入された**ため
     （カード記載値どおり。抽出エラーではない）。
2. **決算収支表（歳入A/歳出B/差引C/繰越財源D/実質収支E）は前年度・当年度の2列。**
   当年度=右列（識別文字Ａ〜Ｅの後ろの2番目の数値）を採用。
   差引Ｃはラベル「歳入歳出差引額」と数値行（Ｃ …）が別の行に割れる年度があるため、
   ラベル行の直後2行まで探索する。
3. **実質収支比率のレイアウトがH19〜H21だけ特殊。**
   ラベル行には「％」だけがあり、本則の値がラベルの1行上、
   臨時財政対策債発行可能額を分母に含めない参考値が括弧付きで1行下に置かれる
   （例: H20 は上に 5.4、下に (5.5)）。本則の値（上の非括弧値）を採用。
   さらに「※実質収支比率（ ）は分母に…」という注記行が同語を含むため除外処理を入れた。
4. **実質公債費比率はH17・H18は簡易様式**（「実 質 公 債費 比率 11.2 ％ 12.1 ％」の
   前年度・当年度2列）、H19以降は健全化判断比率欄の2列。いずれも右端の値=当年度を採用。
   H19のみ導入初年度で当年度1列のみ。
   なお H17カードの当年度値12.1に対し、H18カードの前年度列は12.0（公表後の数値修正と
   みられる差異）。CSVは各年度自身のカードの値を採る。
5. **将来負担比率**はH19が初出（1列のみ95.5）、H20以降2列。右端=当年度を採用。
   R03カードに「※算定誤りにより、令和２年度の将来負担比率を訂正している。」の注記あり。
   R02カード自体の値（42.4）とR03カードの前年度列（42.4）は一致しており、CSVのR02値は
   訂正後の値である。
6. **経常収支比率**は表本体のラベルが行末にあり、値「NN.N ％」は次行（投資的経費の行の
   右端）に印字される。ラベル行から4行以内の最初の「数値 ％」を採用。
   臨時財政対策債（H14〜は減税補てん債含む）を経常一般財源から除いた場合の参考値
   （例: R06 92.1%）は**採っていない**。本則値のみ。
7. ラベルの文字間空白が年度・箇所によりバラバラ（「実 質 公 債費 比率」等）のため、
   全ラベルを「各文字の間に \s* を挟んだ正規表現」で照合している。
8. △は負数として解釈（本CSVの対象列では実質収支等が全年度正のため出現せず）。
   「―」「−」は欠損扱い。

## 各列の定義メモ

- 金額列はすべて**千円**（カードの表示単位のまま）。
- `地方税_千円` = 歳入内訳表「地方税」の決算額（市町村民税内訳表の合計とは別セル、値は同一）。
- `積立金現在高_千円` = 財政調整基金+減債基金+特定目的基金の合計（カードの注記どおり）。
- `人件費/扶助費/公債費/普通建設事業費` = 性質別歳出の決算額列。
  公債費は「公債費比率」「実質公債費比率」行、人件費は「うち人件費」行を除外して抽出。
- `財政力指数` はカード表記の桁をそのまま文字列で保持（例: 0.990, 1.00）。

## 整合チェック（全23年度）

`歳入総額A − 歳出総額B = 歳入歳出差引C` および `C − 翌年度繰越財源D = 実質収支E` を
全年度で検算 → **23年度すべて一致（不整合ゼロ）**。スクリプト実行時に標準出力へ出る。

追加で、各年度カードの「前年度列」（A・B・E）と前年度カードの当年度値を突き合わせる
クロスチェックを実施 → **22年度ペア×3項目で不一致ゼロ**。
列の取り違え（前年度列を当年度と誤認する類のバグ）が無いことの傍証。

## 取れなかった項目・断念事項

- ラスパイレス指数: 様式に無いため全年度空欄（上述）。
- 経常収支比率の参考値（臨財債等控除後）: 対象外として不採用（本則値のみ）。
- H14〜H24の「1.1時点」人口: カードに存在しない（3.31時点のみ記載）。
  `住基人口_基準日` 列で判別可能にした。
